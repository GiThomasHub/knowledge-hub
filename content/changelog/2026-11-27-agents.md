Das Thema **Agenten, Harness und Workflows** hat jetzt sieben Lektionen: Chatbot, Workflow oder Agent mit der ReAct-Schleife, Agent = Modell + Harness, einen Agenten bauen (Messages API und Claude Agent SDK), Muster nach Anthropic, Rechnen vs. Interpretieren, Frameworks wählen sowie die einfachste tragfähige Architektur und die Risiken autonomer Agenten. Dazu 21 neue Fragen (Entwurf) und fünf Glossarbegriffe.

Hinweis aus der Doku-Prüfung: Im Claude Agent SDK ist `allowed_tools` eine Vorab-Freigabe, keine Werkzeugliste. Für unbeaufsichtigte Lese-Agenten braucht es zusätzlich `permission_mode="dontAsk"`.
